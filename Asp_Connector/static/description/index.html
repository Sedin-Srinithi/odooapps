🔑 How to Get Your Activation Code

After installing the module, you need an activation code from Sedin Technologies to start sending invoices. Follow these simple steps:

1.

Install Module

Install from Odoo Apps Store. Auto-registered in background.

2.

Request Activation

Go to Settings → Companies → Your Company → click "Request Activation" button.

3.

We Contact You

Our team contacts you within 2 business days and shares your activation code.

4.

Enter & Activate

Enter the code in Company Settings → click "Verify & Activate". You're ready to send invoices!
